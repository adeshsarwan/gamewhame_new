Draw The Path

Puzzle

About Draw The Path

Draw The Path mixes drawing and puzzle solving. Instead of directly controlling the object, you create a route that helps it reach the intended destination. The fun comes from experimenting with line placement and finding a path that works reliably.

How to play

Draw a path with your mouse or finger, then let the level play out. Adjust the angle, length or position of the route when the object misses the target.

Tips

Use simple lines first. Complicated routes are harder to predict and are not always necessary.
