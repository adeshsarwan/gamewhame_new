# GameWhame v1

Cloudflare-ready static website with five embedded Construct HTML5 games.

## Deploy
Connect this repository to your existing Cloudflare Workers/Pages static-assets deployment. The root of the repository is the deploy directory; no build command is required.

## Important before commercial launch
1. Replace `support@gamewhame.com` if needed.
2. Update legal pages for your actual company/jurisdiction.
3. Configure a Google-certified CMP where required.
4. Replace placeholders in `assets/js/gam.js` with real GAM network code/ad unit paths and implement GPT after the units are created.
5. Replace `ads.txt` with the authorized seller lines generated by GAM/AdSense.
6. Verify every game on desktop and mobile.

Raw game exports live under `/games/` and are marked noindex through `_headers`. Public/indexable pages are under `/game/<slug>/`.
